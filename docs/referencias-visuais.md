# Referências visuais — Floripa Ghosts

Os arquivos da marca e as fotos de uniformes enviados por Henrique Mazzola foram preservados em `public/brand`.

## Uso na aplicação

- `floripa-ghosts-lockup.png`: assinatura do time no cabeçalho.
- `ghosts-flame-pattern.png`: padrão de chama aplicado na base dos indicadores.\n- `ghosts-flame-clean.png`: referência visual de chama enviada pelo time.
- Os demais arquivos são referências oficiais disponíveis para futuras telas, landing page e materiais de comunicação.

As imagens de uniforme não são usadas como fundo de conteúdo operacional para manter contraste e leitura dos dados.
